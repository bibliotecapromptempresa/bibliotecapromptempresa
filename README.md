# 📚 bibliotecadeprompt

**La enciclopedia libre de prompts en español.** 228 plantillas de prompts para ChatGPT, Claude, Gemini y Copilot: gratis, sin registro y listas para rellenar con tus datos.

👉 **[bibliotecadeprompt.com](https://bibliotecadeprompt.com)**

- 🔎 Busca lo que necesitas (resumir, estudiar, buscar trabajo, reclamar, programar…) o cuéntaselo al asistente de la portada.
- ✍️ Rellena tus datos y copia el prompt, o ábrelo directamente en ChatGPT o Claude.
- 🖼️ [Prompts de imagen con ejemplo](https://bibliotecadeprompt.com/imagenes).
- 🔌 [Conector para tu IA](https://bibliotecadeprompt.com/#/conectar): Claude, ChatGPT o Cursor buscan y rellenan los prompts por ti (servidor MCP de solo lectura).
- 🤝 Colaborativa: con una cuenta gratis guardas tus favoritos con ★, publicas tus prompts y propones mejoras.

**Lista completa en GitHub:** [prompts-en-espanol](https://github.com/bibliotecapromptempresa/prompts-en-espanol)
